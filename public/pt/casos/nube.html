O contexto

Uma empresa trabalhava sobre uma base de dados antiga, crítica para o seu dia a dia.

O desafio

O sistema era difícil de manter, caro de escalar e dependia de conhecimentos muito específicos. Qualquer alteração era um risco para o negócio.

O que fizemos

  • Auditoria dos dados e dos processos que dependiam deles.
  • Desenho da nova base de dados na cloud e de um plano de migração por fases.
  • Migração e validação dos dados sem interromper a operação.
  • Cópias de segurança automáticas, monitorização e documentação para a equipa.

Tecnologia

  • Bases de dados na cloud
  • Migração automatizada
  • Monitorização

O resultado

Dados na cloud com cópias diárias e monitorização, e um sistema que já não depende de uma só pessoa.
